# Teeko 可點擊原型

這是一個無後端、以模擬資料驅動的繁體中文單頁原型。路由、作品、課堂和學生狀態保存在瀏覽器 `localStorage`，教師端與學生端透過 `BroadcastChannel` 在同一瀏覽器的分頁之間同步。

AI 生成完成後會先進入作品編輯頁，並保留為未儲存草稿，此時主操作顯示「儲存課件」。只有教師明確儲存後，課件與配套題才會加入個人作品庫；已儲存且沒有待儲存修改時才可建立課堂。教師修改教學內容或配套題後，作品進入「有未儲存修改」狀態，主操作改為「儲存修改」，再次儲存成功前不能建立課堂。

從資源廣場選擇「使用並修改」時，不會顯示從零創作課件的生成步驟；任務頁改為「讀取平台資源 → 複製作品內容 → 建立未儲存草稿 → 生成配套題 → 準備進入編輯」，完成後才進入作品編輯頁。

已儲存作品的內容修改採用「提交修改 → 生成候選版本並直接顯示預覽 → 繼續修改或套用新版本 → 儲存修改」流程。教師可反覆以最新候選版本為基底提出下一輪要求；原型會模擬知雀逐輪返回新的版本識別、託管連結和內容摘要。候選版本套用後只進入未儲存編輯稿，教師再次儲存修改成功後才更新已儲存版本。

## 執行

在專案根目錄執行：

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

然後開啟 `http://127.0.0.1:4173/teeko-prototype/#/signin`。

## 示範資料

- 示範教師電郵：`teacher@teeko.hk`
- 未啟用教師電郵：`new@teeko.hk`
- 示範啟用碼：`TEEKO-HK-2026`
- 課堂代碼：每次建立課堂時即場產生六位數代碼

候課室的「開啟學生端預覽」可在另一分頁模擬學生平板。學生與教師分頁會同步教學內容、作品操作效果、正式題、投票、信號燈及課堂結束狀態。


所有資料均為原型模擬，不會傳送到外部服務。
